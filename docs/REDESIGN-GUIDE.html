6. Antes vs Depois

Mudanças concretas entre o design atual (Cyber-Military Elite) e o proposto (Precision Dark).

❌ Atual (Amador)
Glassmorphism pesado (blur 22-28px) em tudo
Glow neon trifásico em textos e métricas
Bordas com conic-gradient animado (spinning)
Ticks táticos (::before) nos cantos dos cards
Texto secundário com 42% opacidade (ilegível)
Gradient text em títulos de página
whileHover={{ x: 2 }} em nav items
Scrollbar verde neon
Fundo #000000 puro (sem nuance)
Cards definidos por bordas brilhantes
✅ Proposto (Profissional)
Superfícies sólidas zinc-950/900, sem blur
Cor flat, sem text-shadow; acento só em estado
Bordas estáticas 1px rgba(255,255,255,0.08)
Cards definidos por espaçamento e superfície
Texto secundário #A1A1AA (WCAG AA compliant)
Títulos em Inter 600, cor branca, tracking tight
Transições funcionais 120-150ms, sem micro-anim
Scrollbar neutra 3px, thumb zinc-700
Fundo #09090B (zinc-950, profundidade real)
Separação por whitespace, não por glow

7. Tokens CSS de Partida

Substituição direta para o :root do globals.css atual. Compatível com Tailwind via referência.

/* globals-v2.css — Precision Dark Tokens */ :root { --background: #09090B; /* zinc-950, não #000 */ --surface: #18181B; /* zinc-900 */ --surface-hover: #27272A; /* zinc-800 */ --border: rgba(255,255,255,0.08); --border-strong: rgba(255,255,255,0.14); --text-primary: #FAFAFA; /* zinc-50 */ --text-secondary: #A1A1AA; /* zinc-400, era 0.42 opacity */ --text-muted: #52525B; /* zinc-600 */ --accent: #00FF41; /* Matrix green mantido */ --accent-dim: rgba(0,255,65,0.12); --accent-text: #4ADE80; /* green-400, legível em dark */ --danger: #EF4444; --warning: #F59E0B; } /* Remover: .glass, .glass-card, .ticks, .neon-border, .metric-value (glow), .neon-matrix, .neon-electric, .btn-primary (conic-gradient spin), @keyframes border-spin */ /* Adicionar: superfícies sólidas, bordas estáticas, transições 120-150ms, focus ring com outline offset */

8. Referências Visuais

Dashboards e ferramentas que exemplificam o estilo Precision Dark. Estude a hierarquia, espaçamento e uso de cor.

Linear

Referência #1 em UI dark profissional. Bordas sutis, tipografia impecável, animações funcionais. Note como o roxo é usado apenas para estado ativo.

linear.app

Vercel Dashboard

Métricas em mono, tabelas limpas, badges de status minimalistas. O preto tem nuance (não é #000). Cards usam superfície, não borda.

vercel.com/dashboard

Raycast

Lista densa com hierarquia perfeita. Labels muted, valores em destaque, zero decoração. Prova que dark pode ser legível e elegante.

raycast.com

Resend / React Email

Dashboard de analytics dark com gráficos clean. Métricas grandes em branco, labels pequenos e muted. Uso de cor restrito a estados.

resend.com
